# PetCity 可点击网页演示（示例数据）

在线演示：https://iyi04521.github.io/petcity-demo/ （手机、电脑浏览器都能直接打开）

香港宠物友好出行与路线规划小程序的界面原型，用于结题展示。纯静态 HTML / CSS / JS，无需安装、无需联网。

## 怎么打开

- 双击 `index.html` 即可（离线可用，不依赖任何网络资源）。
- 或在本文件夹运行 `python3 -m http.server 8000`，浏览器打开 `http://localhost:8000`。
- 手机宽度（约 390px）显示底部标签栏；电脑宽度（768px 以上）显示顶部导航，地图和详情左右分栏。拖动浏览器窗口宽度即可看到切换。
- 右上角（电脑）或「我的」页（手机）有「重置演示」，会清空本机保存的购物车、订单、档案和行程，回到起点。

## 流程地图（对应 UI 稿页面编号）

| 流程 | 入口 | 页面 |
|---|---|---|
| 建档 | 首次打开 | P0 宠物档案（可点「先逛逛」用示例档案） |
| 地图 | 底部「地图」/ 顶部「地图」 | P1 地图首页、P1a 地点卡片、P2 点位详情（规则、核验日期、设施、评价、反馈） |
| 路线 | 地图首页「全部」 | P3 路线列表（官方 / 我的）、P6 路线详情 |
| AI 辅助排路线 | 「帮我排一条路线」 | P4 四步选择 → P5 路线编辑（上下移、停留时间、加减站、实时距离和用时、规则冲突提示）→ 保存 |
| 去起点 | 路线详情「开始路线」 | P7 导航 / 打车（模拟三步）/ 我已在起点；P7a 到起点了吗 |
| 行程 | 「我已在起点」或「我到了」 | P13 行程中、P13a 到达现场（停留倒计时、延长、拍照、规则反馈）、P13b 进不去换一站、P13c 剩余路线重排、P14 行程小结 |
| 社区 | 「社区」 | P8 帖子 / 活动列表、P9 帖子详情和回复、P10 发帖、P11 活动报名 |
| 商城 | 悬浮购物球、「商城」 | S1 商城首页、S1a 路线装备包、S2 商品详情、S3 购物车、S4 确认订单、S5 收银台（Alipay HK / WeChat Pay HK / Octopus / 信用卡，均为模拟）、S6 支付成功和订单详情、S7 我的订单 |

## 哪些是模拟的

- 所有地点、规则、核验日期、营业时间、价格、评价、帖子、活动、订单均为**示例数据**，页面上都有「示例」标记，不代表真实情况，也未经核验。
- 地图是按真实经纬度手工简化绘制的香港示意图（西九龙、维多利亚港、香港岛全岛），海岸线和道路只是近似轮廓，不能用于导航；
- 示例点位覆盖 4 个区：西九龙、油尖旺（九龙侧）和中西区、湾仔（港岛侧），共 5 条官方路线；港岛几个地标的坐标已对照公开资料核对；
- 地名和图钉重叠时，地名会自动移到上方 / 下方，避不开时暂时隐藏，放大后会再出现；定位、导航、打车、叫车接单、支付、AI 排路线均为模拟，不会调用任何真实服务，也不收集定位、卡号或个人资料。
- 距离和用时按两点经纬度的直线距离 × 1.15、步行 75 米 / 分钟估算，与 UI 稿文档里的数字会有出入。
- 「帮我排一条路线」用预设规则排（`views-map.js` 的 `genRoute`），不调用真实 AI：按体型过滤地点；只用所选区域的点，不够时只从同一侧（九龙 / 港岛）补，不跨海；按营业时间 / 预约时段自动推迟出发时间；本区没有对应活动的点时，会在路线说明里写明借用了哪个邻区的点，或略过了哪项活动。没有示例数据的区（东区、沙田）会用同侧的示例区代替并提示。
- 行程中「进不去？换一站」只推荐 600 m 内、适合当前宠物体型的地点（`views-trip.js` 的 `REPL_R`）；港岛示例点较疏，部分站附近没有替换站，会提示直接跳过。
- 行程里的时间是模拟时钟；到达现场的倒计时加速为 1 秒 ≈ 1 分钟。
- 数据只保存在本机浏览器（localStorage，键名 `petcity-web-demo-v1`），不会上传。

## 怎么改数据

所有示例数据都在 `js/data.js`：

- `PC.POIS`：地点（经纬度 lat / lon，可从地图软件直接复制；类型、体型上限、规则、设施、营业时间、停留时间）
- `PC.ROUTES`、`PC.SEED_MY_ROUTE`：官方路线和预置的「我的路线」
- `PC.PRODUCTS`、`PC.PACKS`：商品和各路线的装备包
- `PC.PAYS`、`PC.TAXIS`：支付方式和叫车选项
- `PC.SEED_POSTS`、`PC.EVENTS`：社区帖子和平台活动
- 想让新区域出现在「区域」筛选和「帮我排路线」里：把区名加进 `PC.DEMO_DISTRICTS`
- 地图图钉和地点列表的分类颜色 / 图标：`core.js` 的 `PC.CAT`，颜色在 `css/style.css` 的 `.cat-*`
- 常量：`GEO`（地图经纬度范围）、`MPU`（地图坐标 1 单位 = 多少米）、`DETOUR`（绕路系数）、`WALK`（步行速度）、`SHIP`（运费）、`COUPON`（示例优惠券）

改完保存，刷新页面即可：程序会发现示例数据变了，自动清空旧的购物车、订单、路线和行程（宠物档案和设置保留）。主题颜色在 `css/style.css` 开头的变量里。

## 文件

- `index.html`：页面骨架
- `css/style.css`：样式（响应式断点 768px）
- `js/`：`data.js` 数据，`hkmap.js` 香港底图（海岸线、绿地、道路、隧道、天星小轮、地名，均为经纬度），`core.js` 状态、计算和路由，`map.js` 示意地图，`ui.js` 公共界面，`views-*.js` 各页面，`icons.js` 内联图标

## 简繁切换

- 电脑版顶部导航、「我的」页右上角、「设置」页都有切换按钮；选择会保存在本机，刷新后保持。
- 繁体使用台湾常用字形（裡、著、線、週）。数据本身始终是简体，只在显示时转换，所以筛选、搜索都不受影响；搜索框输入繁体也能搜到。
- 对照表在 `js/i18n.js`，**只收录了本演示文案用到的字**（约 260 个）和少量按词判断的词组（公里、一隻、複製、回覆…）。用户自己输入的内容如果用到表外的字，可能会有个别字没转换；新增文案后发现漏转，把「简繁」两个字加进 `S2T` 即可。正式产品建议改用 OpenCC 之类的完整词库。
- 不想被转换的内容加 `translate="no"`（例如「简」切换按钮本身）。

## 无障碍

- 弹窗打开时，背景页面不能点击、不能用 Tab 聚焦，读屏软件也不会读到；Tab 只在弹窗内循环，Esc 关闭后焦点回到原来的按钮。
- 地图可以用 Tab 聚焦，方向键移动（按住 Shift 移动更多），+ / − 缩放。
- 所有只有图标的按钮都有中文 `aria-label`。

## 写页面时的约定

- **样式**：常用样式用 `css/style.css` 末尾的工具类，不要再写 `style="…"`。命名规则：
  - `fs-13`（字号 13px，`fs-11-5` = 11.5px）、`mt-8` / `mb-8` / `py-14` / `px-12`（外 / 内边距）、`w-40` / `h-42` / `w-full`
  - `d-flex` / `d-block`、`ai-c`（垂直居中）、`jc-sb`（两端对齐）、`fd-col`、`flex-1`
  - `ta-l` / `ta-r`、`fw-7`（加粗）、`c-muted` / `bg-soft`（颜色）、`pos-rel` / `pos-abs`、`op-35`（透明度）、`bt-line` / `bb-line`（分隔线）
  - 只有和变量相关的样式（例如地图坐标、进度百分比）才写 inline。
- **拼 HTML**：新代码用 `PC.html` 模板，插入的文字会自动转义：
  ```js
  PC.html`<b>${pet.name}</b>${PC.raw(PC.ic('paw', 16))}`
  ```
  图标或已经拼好的 HTML 用 `PC.raw()` 包起来；数组会自动拼接。示例见 `views-social.js` 的 `postCard`。
- **页面计时器 / 监听器**：用 `PC.leave(fn)` 登记清理函数，换页或重绘时会自动执行，可以登记多个。
- **新按钮**：只有图标、没有文字的按钮要加 `aria-label`。
- **局部更新**：同一页内调用 `PC.refresh()` 只会改动有变化的节点，输入框内容和焦点会保留；不用再手动把焦点放回输入框。
